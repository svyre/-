# Как запустить «на себе»

В архиве — исходный проект актуальной опубликованной версии: новый логотип, три уровня сложности и режимы одиночной игры, команды и ведущего.

1. Распакуйте архив.
2. Установите Node.js 24 или новее и pnpm, указанный в package.json.
3. Откройте терминал в папке na-sebe и выполните:

```sh
pnpm install
pnpm dev
```

Локальное приложение откроется по адресу http://localhost:5173. Это проект React / TypeScript с серверной частью Cloudflare Workers и D1; его нельзя запустить двойным щелчком по HTML-файлу.

Для командной игры нужна база D1 с таблицей game_rooms: схема находится в drizzle/0000_powerful_jazinda.sql. Инструкция и команды проверок — в README.md.

Проверено перед публикацией: типы TypeScript, сборка, 15 проверок игровой модели и 94 запроса к обработчику комнат; интерфейс на компьютере и телефоне. Все три цели достижимы на всех уровнях сложности.

Служебные сессии, базы с игровыми данными, зависимости и ключи доступа в архив не включены.
