# Проверка предупреждения Microsoft Defender

Дата: 27 октября 2026 года, Екатеринбург.

Defender сообщил `Trojan:Script/Ulthar.A!ml` в прежнем `na-sebe-reviewed.zip`, указав `index.html` и `source/build.mjs`. Исходный ZIP на GitHub совпал с локальной копией. Причина оценки Defender не установлена. Пользователь сообщил, что VirusTotal не нашёл вирусов; сам отчёт VirusTotal независимо не проверялся.

**Проверка Windows Defender в этой среде недоступна. Результаты ниже не отменяют его предупреждение. Не отключайте защиту и не добавляйте исключения. Если новый ZIP также отмечается, оставьте его в карантине.**

## Новая структура

Готовая игра состоит из отдельных HTML, JavaScript, CSS и ресурсов. В архив для запуска не включены инструменты разработки и исходники. HTML не содержит встроенного исполняемого кода или двоичных данных base64. CSP запрещает внешние сетевые вызовы; отдельный браузерный тест подтвердил блокировку искусственного запроса. Игра не отправляла внешних сетевых запросов в проверенных потоках.

Пройдены 60 проверок, полный год, покупки мебели, все 60 ситуаций, смена персонажа, CSV, старые сохранения и пауза. Повторная сборка побайтно воспроизвела все 14 готовых файлов сайта. Код модели и интерфейса совпадает с предыдущими исходниками. Подробности: [SECURITY_STATUS.md](../web-game/SECURITY_STATUS.md), [каждый файл проекта](../web-game/FILES.md).
