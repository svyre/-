# Готовая игра «На себе»

**История и обучение:** [игра — ZIP, 1,3 МБ](https://github.com/svyre/-/raw/refs/heads/download-na-sebe-game/downloads/na-sebe-story.zip) · [полный проект — 3,1 МБ](https://github.com/svyre/-/raw/refs/heads/download-na-sebe-game/downloads/na-sebe-story-source.zip) · [сайт](https://svyre.github.io/na_sebe/). 36 ежемесячных глав, трое возвращающихся знакомых и ответы, которые вспоминаются дальше. В новой партии десять шагов обучения знакомят с комнатой, ситуациями, планом, развитием и банком. Обучение можно пропустить или открыть снова. Разговоры сохраняются в истории и входят в итоговый CSV. Режимы на 1–3 года, хардкор, 132 финансовые ситуации и совместимость прежних сохранений сохранены. Пройдены 114 проверок, 36 и 24 месяца через интерфейс. [Назначение всех 131 файла](../web-game/FILES.md).

Распакуй архив целиком и открой `index.html` в современном браузере. Сохрани рядом `app.js`, `styles.css`, `favicon.svg` и папку `assets`. Установка Node.js для игры не нужна. Для публикации на GitHub Pages загружай все эти файлы и `.nojekyll`.

Обучение начинается только в новой партии. В сохранённой игре его можно открыть кнопкой «Обучение» под заголовком месяца. Прежний прогресс остаётся на том же устройстве и адресе сайта. Ответы в разговорах и шаг обучения сохраняются сразу; незавершённый финансовый план по-прежнему сбрасывается при перезагрузке.

Проверены десять шагов, пропуск и повтор, восстановление шага, журнал разговоров, финал и CSV. Через интерфейс пройдены 36 месяцев «Баланса» и 24 месяца хардкора. На ширинах 320–1440 пикселей нет горизонтального переполнения; ошибок JavaScript, внешних запросов и нарушений CSP не обнаружено.

Полный проект содержит исходники, справочник файлов и команды сборки. Зависимости `node_modules` не включены. Обычный архив для игры содержит только 17 файлов, нужных для запуска и сопроводительных документов.

[Отчёт о проверке архивов и SHA-256](SECURITY-CHECK.md). ClamAV не обнаружил угроз; повторная проверка Microsoft Defender в этой среде недоступна. Результаты разных антивирусов не равнозначны.
