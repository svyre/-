## Режимы

- **Соло:** прогресс на устройстве, история операций, итоговый разбор и сравнение альтернативного решения.
- **Команда:** вход по коду, общее событие месяца и фиксация плана до перехода ведущего.
- **Ведущий:** до 24 команд, таймер-ориентир, пауза, переход после готовности всех команд, экран для проектора и экспорт CSV.

## Запуск и проверка

Используется Vinext / React / TypeScript, серверные маршруты Cloudflare Workers и D1. Установите зависимости поддерживаемым менеджером проекта, затем `npm run dev`. Полный путь размещения и подготовка проекта описаны в `.openai/hosting.json` и поддерживаемых скриптах Sites.

- `npm run test:game` — денежный учёт, проценты, комиссии, погашение кредитов, ограничения времени, скрытые последствия, отложенные обязательства и воспроизводимость альтернативной траектории.
- `npm run test:rooms` — серверный обработчик с D1-совместимым адаптером SQLite в памяти: конкурентная запись, права ведущего, скрытые данные, пауза, готовность и полный год для двух команд. Требуется Node.js с модулем `node:sqlite` (24+).
- `npx tsc --noEmit` — проверка типов.
- `npm run db:generate` — генерация новой миграции после изменения схемы.

## Структура

- `lib/game.ts` — независимая детерминированная модель и 12 сценариев.
- `app/ui/` — экраны и клиентское управление состоянием.
- `app/api/room/route.ts` — комнаты, серверная проверка ходов и оптимистическая блокировка версии.
- `db/schema.ts`, `drizzle/` — схема и миграции D1.

Комнаты действуют 7 дней. Названия команд заменяют персональные профили. Ключи доступа ведущего и команды сохраняются только в браузере, в базе хранятся их SHA-256 хеши; они не входят в ссылки приглашения. Входы сохраняются отдельно, чтобы можно было вернуться из обзора.

Новый экземпляр размещается с закрытым доступом. Для занятия участникам также требуется доступ к приложению. Публикация или изменение аудитории управляются отдельно от кода комнаты.

## Упрощения модели

Подробные правила находятся в разделе «Как играть». Начисление процентов — помесячное, новые переводы начинают приносить доход со следующего месяца. Рыночный сценарий фиксирован, будущая доходность не показывается в прогнозе. Все команды получают одинаковые внешние события. Капитал вычитает остаток кредитов и будущие отложенные платежи; чистый резерв исключает фонд и вычитает те же обязательства. Жильё можно менять ежемесячно без платы за переезд. Налоги, правовые требования и страхование вкладов не моделируются.
