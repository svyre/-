# Карта Minecraft — без спойлеров

Для одного игрока, Minecraft Java Edition **1.21.1**. Датапак уже встроен, моды не требуются.

[Скачать готовую карту (ZIP)](https://raw.githubusercontent.com/svyre/-/refs/heads/minecraft-surprise-1.21.1/Minecraft_surprise_Java_1.21.1.zip)

Распакуй архив и перенеси папку `Posledniy_signal` в `.minecraft/saves`. Затем открой мир в одиночной игре. Подробная инструкция без спойлеров находится в `START_HERE.txt` внутри архива.

Структура мира и команды проверены автоматически. Запуск в игровом клиенте не проверен.
